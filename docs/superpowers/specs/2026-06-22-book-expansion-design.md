# 全书扩写工程设计

**日期**: 2026-06-22
**目标**: 将《学习的地形》12章全部拉到 Ch5（564行）基准，叙事血肉与数学筋骨并重，中英双语同步完成。

---

## 一、目标

当前 11 章（Ch5 除外）需扩写至 500-600 行。总计需增加 ~3,300 行中文 + ~3,300 行英文。

## 二、两线方法论

### 线 1：叙事血肉（先做）

贯穿全部 11 章（中+英），统一标准：

- **叙事开篇**：每章必须有 ≥1 个 embodied metaphor（蒙眼徒步、洞穴潜水、滑雪选路、墨脱公路、煮汤等），无公式，纯空间直觉
- **Section 过渡**：每对相邻 section 之间必须有 2-4 句叙事胶水，用同一隐喻串联。禁止"接下来我们讨论 X"
- **兔狲教授 :::info**：每章 ≥2 个立场评论块，用清晰不妥协的几何语言
- **具体例子/数值演示**：在形式化跳跃处插入 :::info（第一类），每章 ≥2 个
- **叙事收束**："本章小结"前必须有叙事闭合——将所有形式化概念织回隐喻
- **禁词**："显然""众所周知""接下来我们讨论""梯度下降就是调参"

**审查标准：连续 3 个 section 无隐喻或具体例子 → 不合格。**

### 线 2：数学筋骨（后做）

在线 1 的血肉之上加深骨架：

- **定理/定义/性质环境**：每章 ≥5 个显式标注块（定理 N / 定义 N / 性质 N）
- **推导链**：每个定理/性质必须有推导或证明草图，不能凭空出现
- **交叉引用**：每章 ≥2 条显式的跨章理论连接
- **Master equation**：$S_{t+1} = S_t + \eta F_\theta(S_t, x)$ 在每章至少出现 1 次
- **公式一致性**：中英两版公式完全一致

**审查标准：每章 ≥5 个显式定理/定义/性质块 + 推导链 + 交叉引用。**

## 四、扩写顺序

**线 1**: Ch10 → Ch11 → Ch12 → Ch8 → Ch4 → Ch7 → Ch9 → Ch6 → Ch2 → Ch1 → Ch3

**线 2**: Ch10 → Ch8 → Ch7 → Ch11 → Ch12 → Ch4 → Ch6 → Ch1 → Ch2 → Ch9 → Ch3

线 1 和线 2 不完全独立——线 1 扩写时顺手补明显的数学缺口（如 ch10 一个定理都没有，加血肉时可能需要先定义几何对象）。

## 五、单章工作流

### Step 1：诊断（读）
读该章中英双版，标记叙事和数学缺口位置。

### Step 2：执行（写）
按缺口清单逐项写入中文版，每完成一个 section 立即同步翻译为英文版对应 section。

### Step 3：审查（验）
- 对照线 1/线 2 标准自查
- `npm run docs:build` 通过
- 中英行数差异 ≤5%

## 六、双语同步

- **中文为源，英文为精确翻译**
- 不在英文版额外创作内容——所有新增内容先写入中文版，再逐段翻译为英文
- 修改中文版一个 section → 立即修改英文版对应 section
- 不允许"做完 11 章中文后才翻译英文"

## 七、质量门

### 线 1 完成标准
- ✅ 叙事开篇 ≥1 个 embodied metaphor
- ✅ 每对相邻 section 有 2-4 句叙事胶水
- ✅ ≥2 个兔狲教授 :::info 立场评论
- ✅ ≥2 个第一类 :::info（具体例子/隐喻展开）
- ✅ 连续 3 个 section 无隐喻/例子 → 不合格
- ✅ 禁词零容忍
- ✅ 英文版血肉不缩水

### 线 2 完成标准
- ✅ ≥5 个显式定理/定义/性质标注块
- ✅ 每个有推导链或引用链
- ✅ Master equation ≥1 次
- ✅ ≥2 条跨章理论连接
- ✅ 中英公式一致

### 全局完成标准
- ✅ 所有 11 章通过线 1 + 线 2 标准
- ✅ `npm run docs:build` 零错误
- ✅ 中英双版行数差异 ≤5%

## 八、决策摘要

| 维度 | 决策 |

| 目标行数 | 500-600 行/章，以 Ch5 为基准 |
| 策略 | 两线推进：先线1（叙事血肉），后线2（数学筋骨） |
