# 第 1 章：为什么学习需要几何

如果推理不是一句答案，而是一种结构性活动，那么我们应该怎样刻画这种结构？

当一个模型读到一道题，它并不是在虚空中突然吐出一个答案。它会把题目变成表示，把表示送进一层又一层的变换，把局部线索组织成全局判断，再把若干可能答案压缩成一个最终输出。这个过程中，有方向，有位置，有距离，有路径，有弯曲，有靠近和远离，有稳定和不稳定。

这些东西合在一起，就已经不是单纯的"计算"了。它更像一种几何。

所谓几何，并不只是画三角形、圆和坐标轴。几何最深的工作，是刻画结构。它问的是：对象在哪里？对象之间有多远？一个方向意味着什么？一个空间如何弯曲？一个运动如何被限制？一个系统怎样从一个状态走向另一个状态？

如果我们把学习看成结构性问题，那么几何就不是装饰，而是必需品。

但在讨论学习之前，我们需要先理解"空间"和"运动"这两个词从哪里来。它们不是天然就长成今天这个样子的。

## 1.1 从力到能量：一个改变世界的故事

在经典力学中，我们最熟悉的是牛顿方程：

$$F = ma$$

它很强，强到几乎可以成为现代科学的象征。只要知道物体受到什么力，我们就能知道它如何加速；只要知道它如何加速，我们就能预测它未来的位置。

但是，牛顿方程也有一个很现实的问题：你必须把力分析清楚。

一个小球在斜面上滚动，你要分析重力、支持力、摩擦力。一个摆在运动，你要分析张力和重力。一个复杂机械系统里有多个部件、多个约束、多个方向，受力分析很快就会变成一张混乱的图。你当然可以继续算，但你会发现：真正麻烦的不是运动本身，而是如何描述这个运动。

这时，分析力学提供了另一种语言。它不从"每一个力是什么"开始，而是从一个更整体的量开始：能量。

比如哈密顿量。粗略地说，在许多经典系统中，哈密顿量可以理解成系统的总能量：

$$H = T + V$$

其中 $T$ 是动能，$V$ 是势能。动能描述系统如何运动，势能描述系统处在什么位置、什么形势、什么结构里。

于是，问题发生了变化。我们不再只盯着每一个局部受力，而是把整个系统放进一个能量结构中。系统的运动，不再只是"哪里受了什么力"，而是在一个能量地形中如何流动。

这就是一个非常重要的思想转变：**从力的逐项分析，走向能量地形的整体刻画。**

![牛顿受力分析 vs 哈密顿能量地形](/figures/ch01_newton_vs_hamilton.svg)

*左图：牛顿框架下，同一质点被四个分量力拉扯，分析者必须逐一枚举方向与大小。右图：哈密顿框架下，同一系统被压缩成一张势能等高线，运动轨迹自然沿地形流动——两种语言，同一个物理，但右边的地形一眼可见。*

:::info

**兔狲教授的立场**

牛顿给了我们 $F=ma$。这个公式统治了科学两百年。但它有一个根本的局限：你必须把每一个力都分析清楚。一个球在斜面上，重力、支持力、摩擦力。一个摆在运动，张力、重力。一个复杂系统里有十个部件——你就得分析三十个力。这不是理解，这是会计。

哈密顿说：别数力了。看能量。把整个系统放进一个能量地形里。小球自然会滑到能量最低的地方。你不需要追着每一个力跑——你只需要画一张地形图。

深度学习社区搞了十年才意识到同一件事。我们管它叫"损失函数"。但我们一直在用牛顿的语言谈论它——"梯度下降""参数更新""优化步骤"。这些都是力的语言。力的语言让你算得快，但它不让你看见地形。看见地形，你才会发现：学习不是在黑暗中摸索最优解——学习是在一片能量地形上，沿着最陡的坡往下滑。你看不见地形，是因为你一直在数力。

这本书要做的，就是把你的眼睛从力的表格上抬起来，去看那片地形。

## 1.2 学习也可以被看成一种运动

现在我们回到人工智能。

训练一个模型时，我们通常说：模型要最小化损失函数。

$$\min_\theta \, L(\theta)$$

这里 $\theta$ 是模型参数，$L(\theta)$ 是损失函数。损失越小，说明模型在训练数据上的表现越好。

传统教材通常会在这里直接进入梯度下降：

$$\theta_{t+1} = \theta_t - \eta \nabla L(\theta_t)$$

这当然没错。但如果我们只把它当成一个更新公式，就会错过它真正漂亮的地方。

这个公式其实在说：模型当前站在参数空间中的一个位置 $\theta_t$。损失函数在这个空间上形成了一片地形。梯度 $\nabla L(\theta_t)$ 告诉模型，当前位置附近的地势如何变化。学习率 $\eta$ 决定模型每一步走多远。于是，训练不是魔法，而是模型在损失地形上的运动。

这时，学习就变成了动力学问题——和牛顿力学中物体在势能地形中的运动，在数学结构上完全同构。

模型不是"突然变聪明"的。模型是在一个空间中移动。它走过一些区域，避开一些区域，陷入一些盆地，穿过一些鞍点，最终停在某种相对稳定的位置附近。

这就是学习的地形。

![损失地形与梯度下降轨迹](/figures/ch01_loss_landscape.svg)

*参数空间中的损失地形：椭圆碗形曲面对应各向异性损失 $L = \theta_1^2 + 3\theta_2^2$，橙色轨迹是从初始点出发的梯度下降路径，绿色圆点是收敛终点。注意轨迹并非直线下冲，而是沿地形曲率弯折——这正是"运动"而非"调参"的意义所在。*

## 1.3 但是，"空间"到底是什么？

上两节我们一直在说"空间""地形""运动"，好像这些词的意思不言自明。但如果停下来认真问一句——**空间到底是什么？**——我们就会发现，这个问题的答案远不是"一个装东西的地方"那么简单。

空间、点、向量和距离这些概念，并不是一次性从天上掉下来的。它们经历了漫长的变化。古希腊人用几何理解土地、建筑、天体和秩序；近代物理学用空间描述运动；现代数学把空间推广成集合、流形、拓扑、度量、概率分布；人工智能又把空间带进了参数、表示、嵌入和信念之中。

所以要理解学习为什么需要几何，我们必须先理解"空间"这个词从哪里来，经过了哪些变形，最终为什么成了学习系统的基础语法。

我们从欧几里得开始。

在《几何原本》中，欧几里得把几何建立在一组定义、公设和共同观念之上。点、线、面、角、圆，这些东西被依次摆出来，然后整个几何世界从它们身上展开。其中最有名的定义之一是：**点是没有部分的东西。**

这句话非常奇怪。一个点没有长度，没有宽度，没有厚度。它不能被切开，也不能被看见。可是，整个几何世界却要从这种"没有部分的东西"开始。

为什么？因为点不是一粒小沙子。点是位置的抽象。当我们说"这里有一个点"，真正说的不是这里有一个物体，而是这里有一个可被标记的位置。点把空间变成可以被指认的东西。没有点，空间只是一片模糊的展开；有了点，我们就能说：这里，那里，从这里到那里。

线则是点的连续运动留下的痕迹。面则是线的展开。体则是面的延伸。于是，空间被一层一层组织起来：点给出位置，线给出连接，面给出展开，体给出容纳。这就是欧几里得几何的基本直觉：世界可以被清楚地划分、标记、连接和证明。

我们可以讲一个哲学小故事。这不是严格考据意义上的历史结论，而是一个哲学寓言。

想象一个生活在古代城邦中的人。他每天看到的是广场、石阶、墙壁、柱廊、道路、庙宇和城墙。人的生活空间被建筑切割成直线、平面、角度和比例。城市需要丈量土地，工程需要规划结构，政治需要广场，宗教需要神庙，贸易需要道路。在这样的世界里，平面不是抽象概念，而是生活经验。人走在广场上，测量土地，修筑墙面，设计柱廊。空间被人的工程活动变得平直、可切分、可证明。

这就是为什么欧几里得几何如此迷人。它给人的不是一个真实宇宙的完整图像，而是一种可治理、可丈量、可证明的空间。在这个意义上，欧几里得空间不只是数学空间，也带着文明的痕迹——它来自土地、建筑、城市、工程和政治秩序。它让人类相信：只要找到正确的公设，世界就可以被一步步证明出来。

## 1.4 空间开始运动：从静态秩序到动力舞台

到了近代物理，空间的角色发生了根本变化。

在欧几里得那里，空间主要是几何对象展开的地方——点、线、面、角在其中被构造和证明，是静态的。到了牛顿那里，空间成了运动的舞台。物体在空间中运动，时间在均匀流逝，力改变物体的速度，轨迹描述物体如何从一个位置走向另一个位置。

这时，点不再只是几何点——它可以代表一个质点的位置。距离不再只是两点之间的长度——它可以参与速度、加速度和力的计算。一个物体的位置可以写成 $x(t)$，速度是 $v = dx/dt$，加速度是 $a = d^2x/dt^2$。于是，空间和时间被绑在一起。几何不再只是静态形状的学问，而变成了运动的语言。

这一步对人工智能极其关键。因为学习也正是这样：我们不只关心模型当前在哪里，还关心它如何变化。如果参数是位置，那么训练就是参数随时间变化的轨迹。如果隐藏状态是位置，那么推理就是隐藏状态随层数或步数变化的轨迹。

近代物理给我们的启发是：**空间不是背景板。空间一旦和变化结合，就会变成动力学。**

## 1.5 空间开始弯曲：高斯爬山与黎曼演讲

欧几里得的平面空间统治了两千年。直到十九世纪，有人开始认真测量它。

1820年代，高斯负责测量汉诺威的地图。他爬上山顶，用镜子反射阳光，精确测量三座山峰构成的三角形的内角和。如果欧几里得是对的，内角和应该恰好是 180°。

测量结果：内角和比 180° 大了一点点。

高斯大概率知道这意味着什么——地球是球面，球面上的三角形内角和本来就大于 180°。但他没有发表。原因据说是：他不想跟哲学界争论，因为康德刚刚把欧几里得空间的平直性说成是人类认知的先天必然——不是经验事实，而是思维的前提条件。高斯不想惹这个麻烦。

黎曼在 1854 年的就职演讲里把这件事说清楚了。他提出：**弯曲的空间是完全自洽的。** 在球面上，三角形内角和大于 180°；在双曲面上，内角和小于 180°。这不是错误，这是不同的几何。

更关键的是，黎曼说：距离的概念本身是可以推广的。在平面上：

$$ds^2 = dx^2 + dy^2$$

在一般的黎曼流形上：

$$ds^2 = g_{ij} \, dx^i \, dx^j$$

其中 $g_{ij}$ 是描述空间局部弯曲程度的度量张量。这一步，让"空间"从一个固定的平台，变成了一个可以弯曲、可以在不同区域有不同几何性质的对象。

爱因斯坦 1915 年写下广义相对论时，用的就是黎曼几何：引力不是一种力，而是时空弯曲的几何效应。物体沿测地线运动，就像在弯曲表面上走最短路径。

这对深度学习有直接的含义。参数空间不一定是平的。在参数空间的某些区域，损失函数的曲率很高（尖锐极小值附近）；在另一些区域，曲率很低（平坦极小值附近）。如果我们用固定的欧几里得步长在弯曲的参数空间里走，就像用直尺在球面上测地图——走歪是必然的。自然梯度法（Natural Gradient）正是黎曼几何在优化中的直接应用：用度量张量修正每一步的方向，使步长在参数空间的局部几何里保持一致。

![平面、球面与双曲面上的三角形内角和](/figures/ch01_curvature_triangles.svg)

*三种曲率下的三角形。平面（曲率 = 0）内角和恰为 180°；球面（曲率 > 0）内角和超过 180°，三条边都是大圆弧；双曲面（曲率 < 0）内角和不足 180°。高斯在汉诺威山顶测到的偏差，正是地球曲率在宏观尺度上的微弱显现。*

## 1.6 四个基本词：点、向量、距离、空间

现在我们把这些历史收束起来，正式定义四个对学习至关重要的基本词。

**点是什么？** 点是位置的抽象。在 $n$ 维空间中，一个点可以写成 $p = (x_1, x_2, \ldots, x_n)$。在机器学习里，一张图片被拉平成高维向量后是图像空间中的一个点；一句话被编码成 embedding 后是语义空间中的一个点；整个模型的参数 $\theta$ 是参数空间中的一个点；一个答案分布 $p(y|x)$ 是概率空间中的一个点。点的意义不在于它小，而在于它能被定位。

**向量是什么？** 如果点描述位置，那么向量描述变化。从点 $a$ 到点 $b$，向量 $\mathbf{v} = b - a$ 包含两个信息：方向（往哪里走）和大小（走多远）。在学习中，梯度是向量——它告诉参数应该朝哪里更新。词嵌入是向量——它把语义对象放进一个可计算空间。注意力中的 query、key、value 是向量——它们通过方向和相似性建立 token 之间的关系。

向量最重要的操作是内积：

$$\langle \mathbf{u}, \mathbf{v} \rangle = \sum_{i=1}^n u_i v_i$$

内积同时告诉我们两件事：大小（$\|\mathbf{v}\| = \sqrt{\langle \mathbf{v}, \mathbf{v} \rangle}$）和方向关系（$\langle \mathbf{u}, \mathbf{v} \rangle = \|\mathbf{u}\| \|\mathbf{v}\| \cos\theta$）。内积为零，两向量正交——它们在空间里互相看不见对方。当我们写 $\theta_{t+1} = \theta_t - \eta \nabla L(\theta_t)$，这里的 $-\nabla L(\theta_t)$ 就是一个方向向量——它告诉模型：如果你想让损失下降，就往这边走。

**距离是什么？** 距离回答的问题是：两个对象差多少？在欧几里得空间中，最熟悉的是直线距离 $d(a,b) = \sqrt{\sum_i (a_i - b_i)^2}$。但在人工智能中，欧几里得距离并不总是最合适。

有时候，我们关心方向是否相似，于是使用余弦相似度：$\cos(\mathbf{u}, \mathbf{v}) = \frac{\langle \mathbf{u}, \mathbf{v} \rangle}{\|\mathbf{u}\| \|\mathbf{v}\|}$。"猫"和"猫咪"在词向量空间里方向几乎一致，但向量大小可能不同——余弦相似度认为它们很接近。

有时候，我们关心两个概率分布有多不同，于是使用 KL 散度：

$$D_{\mathrm{KL}}(p \| q) = \sum_i p_i \log \frac{p_i}{q_i}$$

注意，KL 散度不是对称的——$D_{\mathrm{KL}}(p\|q) \neq D_{\mathrm{KL}}(q\|p)$。从确信到混乱，和从混乱到确信，几何意义不同。这不是 bug，而是它在信念空间中天然合适的原因。

距离不是一个固定答案。距离是我们根据空间结构选择的测量方式。什么样的空间，需要什么样的距离。

![三种距离度量对比](/figures/ch01_distance_metrics.svg)

*左：欧几里得距离，等距面是正圆，度量两点间的直线长度。中：余弦相似度，等相似线是从原点出发的射线，"cat"与"kitty"方向接近故相似，"car"方向偏离故不同——向量长度无关。右：KL 散度，两个高斯分布 $p$（蓝）与 $q$（橙）之间，$D_\mathrm{KL}(p\|q) \neq D_\mathrm{KL}(q\|p)$，不对称性反映了"从 $p$ 出发衡量 $q$ 的意外程度"与反方向并非等价。*

**空间是什么？** 最粗略地说，空间是对象可以被放置、比较和变换的地方。在欧几里得几何中，空间允许点、线、面被构造。在牛顿力学中，空间允许物体运动。在向量空间中，空间允许加法和数乘。在度量空间中，空间允许我们测量距离。在概率空间中，空间允许我们比较信念分布。

所以空间不是空的。空间本身就是结构。一个空间规定了什么东西可以比较，什么东西可以移动，什么东西可以靠近，什么东西可以保持不变。当我们说"学习发生在空间中"，我们并不是说学习发生在某个抽象背景里——我们是在说：学习依赖某种结构；没有结构，就没有学习路径；没有路径，就没有推理。

## 1.7 回到学习：几何为什么不可避免

现在我们可以回到本书的核心命题了。

如果学习是运动，那么我们立刻需要回答几个问题。

第一，**模型在哪里运动？** 它当然不是在现实中的三维空间里运动。它运动在参数空间、表示空间、概率空间、信念空间之中。参数空间记录模型的权重位置，表示空间记录输入被编码后的结构，概率空间记录模型对答案的信念分布，信念空间记录推理过程中判断如何变化。

第二，**模型朝哪里运动？** 这需要方向。梯度是一种方向，注意力是一种方向，残差更新是一种方向，推理链中的信念修正也是一种方向。

第三，**模型走了多远？** 这需要距离。欧几里得距离描述向量之间的直线差异，余弦相似度描述方向接近程度，KL 散度描述信念偏差。不同空间需要不同的距离概念。

第四，**模型为什么会停下来？** 这需要稳定性。一个系统可能收敛到极小值，也可能进入振荡，也可能发散，也可能抵达不动点。

于是我们发现，学习需要几何，不是因为几何好看，而是因为没有几何，我们连这些问题都问不清楚。空间、方向、距离、路径、曲率、稳定性——这些不是外部比喻，它们就是学习系统的结构语言。

深度学习经常被说成优化问题。这当然合理，但还不够。优化关心的是"怎样让损失下降"，而学习力学关心的是：模型在什么空间中运动？这个空间有什么地形？运动由什么方程控制？哪些区域是稳定的？哪些区域是危险的？哪些路径能产生泛化？哪些路径只是记住了训练数据？

我们可以用一个最一般的公式把这一切收束起来：

$$S_{t+1} = S_t + \eta F_\theta(S_t, x)$$

这里 $S_t$ 是系统当前状态，$x$ 是输入，$F_\theta$ 是某种由模型决定的更新场，$\eta$ 是步长。如果 $S_t$ 是参数，这是训练。如果 $S_t$ 是隐藏表示，这是深层网络中的特征演化。如果 $S_t$ 是信念分布，这是推理过程中的信念更新。如果最终满足 $S^* = F_\theta(S^*, x)$，那就是不动点——系统找到了一个位置，在那里它对自己的推动恰好为零。

这个公式把学习、推理、状态更新、残差网络、Transformer block、不动点模型，都放进了同一个语言里：**当前状态经过一个场的推动，走向下一个状态。** 它将是贯穿全书的核心方程。

## 1.8 推理的几何直觉

最后，让我们用这个框架重新看一眼推理模型。这将为卷三的整个讨论埋下种子。

推理不是一句答案，而是一条轨迹。一个模型从题目出发，在表示空间中形成初始状态。它通过层与层之间的变换不断更新这个状态。它可能走向正确答案的吸引域，也可能走向错误答案的吸引域。所谓训练，就是改变这片空间的地形，让正确路径更容易走，让错误路径更难稳定下来。

这也解释了一个很有意思的现象：为什么思维链训练有时会提高模型直接输出答案的能力？因为思维链训练不只是训练模型"多写几句话"。更深层地看，它可能改变了模型内部的表示地形。它让模型学会在读题时形成更有结构的中间状态，让正确答案附近的吸引域变大，让错误答案附近的路径变窄。于是，即使模型最后不显式输出思维链，它内部也可能已经学会了更好的运动方式。

显式思维链只是轨迹的文字投影。真正的推理，发生在模型内部的几何地形中。

## 1.9 本章小结

本章做了一件事，但这件事是全书的地基：**把学习从"公式更新"重新看成"空间中的运动"。**

这个转变依赖一个更深的、穿越两千年的理解：空间不是一成不变的。欧几里得的空间是静态秩序——点、线、面在其中被构造和证明。牛顿的空间是运动舞台——物体在其中改变位置，轨迹描述变化。黎曼的空间可以弯曲——距离不再是直线，而是沿测地线的最短路径。而在人工智能中，空间变成了参数、表示、概率和信念发生变化的场所。

点是位置的抽象。向量是变化的方向。距离是结构的测量。空间是这些关系能够成立的场所。

如果学习是运动，那么我们需要空间。如果有空间，我们需要点、向量和距离。如果有距离，我们才能讨论靠近和远离。如果有方向，我们才能讨论梯度和更新。如果有地形，我们才能讨论优化和收敛。如果有收敛，我们才能讨论推理为什么会稳定到某个答案。

因此，几何不是深度学习的装饰语言，而是学习系统的基础语法。

下一章，我们将进入这个语法最具体的一页：**模型的身体在哪里？它的视野是如何形成的？**——参数空间与表示空间，身体与视野，这是我们理解学习地形的第一步。

## 悬而未决的问题

1. 如果学习是模型在某个空间中的运动，那么这个"空间"到底是真实存在的，还是我们为了理解模型而构造出来的语言？

2. 损失函数是否真的可以被看成一片地形？如果可以，那么这片地形是模型自己看到的，还是研究者从外部画出来的？

3. 梯度下降看起来像是在"下山"，但深度学习中的参数空间往往有数百万、数十亿维。在这样的空间里，"山谷""鞍点""盆地"这些低维比喻还可靠吗？

4. 牛顿力学从力出发，哈密顿力学从能量出发。深度学习从 loss 出发。那么 loss 是否可以被理解为人工智能系统中的一种"能量"？如果是，李雅普诺夫函数的思路能否用来严格证明收敛性？

5. 欧几里得把点定义为"没有部分的东西"。在人工智能中，一个 embedding 向量有成百上千个维度，它还能被称为"点"吗？

6. 欧几里得空间强调直线距离。但语义空间中，"猫"和"虎"可能比"猫"和"桌子"更近。这种"近"到底是几何距离，还是统计共现，还是人类意义的投影？

7. 距离是不是一种客观事实？还是说，每一种距离定义——欧几里得的、余弦的、KL 的——都隐含了一种看待世界的方式？

8. 如果空间可以是弯曲的，那么深度学习中的参数空间和表示空间是否也是弯曲的？这种弯曲来自数据，来自模型结构，还是来自训练过程？

9. 在高维空间中，人类的低维直觉经常失效。那么我们用二维图、三维图解释深度学习时，究竟是在帮助理解，还是在制造幻觉？

10. 欧几里得空间来自一种平直、可丈量、可证明的世界经验。那么人工智能时代会不会产生一种新的空间观：由数据、嵌入、概率和信念构成的空间观？

11. 如果推理不是答案，而是一条轨迹，那么我们应该如何观察这条轨迹？看输出文本够吗？还是必须进入隐藏状态、注意力结构和概率分布？

12. 我们能否建立一种新的学习理论：不再只问 loss 是否下降，而是问模型的状态轨迹是否稳定、是否可解释、是否朝向更好的结构区域？

---

**本章留下的核心问题是：**

**如果学习是一种运动，那么我们究竟应该用什么空间来承载这种运动——以及，这个空间长什么样？**

:::info

**学习发生在哪个空间里？这个空间是平的还是弯的？什么东西算"近"，什么东西算"远"？** —— 这些问题将牵引全书：从参数空间到表示空间，从损失地形到信念空间，从不动点到推理轨迹。如果你在这一章停下来，只带走一个问题，请带走这一个。因为在你能回答"模型在哪里"之前，"模型如何学习"永远只是一句空话。

:::
