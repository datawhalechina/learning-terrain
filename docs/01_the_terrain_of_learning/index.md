# 卷一：学习的地形

你在序言里读到了一句话：**力让你算。能量让你懂。几何让你看见。**

这句话是全书的地基。但地基不是房子。你得先知道这片地基上要盖什么。

卷一的三章盖的是第一层楼——也是最关键的一层。因为如果这一层没盖好，后面的九章你都会觉得是比喻。

它不是比喻。

---

想象你是一个盲人，被空降到一片荒野中。你不知道自己在哪里。你不知道最低的山谷在何方。你唯一能感知的，是脚底传来的坡度——向左倾斜还是向右倾斜，坡度陡还是缓。

你的任务是在这片荒野中找到最低点。

这听起来像一个谜题。但这就是深度学习每天在做的事。你**不需要**知道自己在参数空间中的绝对坐标。你**不需要**看到整片损失地形的全貌。你只需要感受脚下的坡度——那个我们叫做"梯度"的东西——然后沿着它指向的方向，迈出一步。再感受。再迈步。

第一章回答：**为什么这件事需要几何？** 从牛顿的力到哈密顿的能量，从欧几里得的平面到黎曼的弯曲空间——两千年来，"空间"这个词经历了五次变形，每一次都离深度学习更近一步。

第二章回答：**什么东西在运动？它看见了什么？** 参数是身体——模型站在参数空间的某个位置上。表示是视野——这个位置决定了模型如何理解世界。身体的每一步移动，都在重塑视野的结构。

第三章回答：**脚下的大地长什么样？** 损失函数不是数字——它是一片能量地形。梯度告诉方向。欧拉步把方向变成位移。山谷、鞍点、盆地——每一种地貌都在决定模型能走多远、停在何处。

---

卷一看似在讲基础。但"基础"不等于"简单"。这三章建立的是全书最核心的逻辑链：

**参数空间是身体 → 损失地形是坡度 → 梯度下降是行走 → 表示空间是视野。**

这条链上的每一个环节，都不是比喻。它是数学。它是可以用偏导数、Hessian 矩阵和动力系统严格描述的东西。

你准备好了吗？第一章从 $F=ma$ 开始——但不是你背过的那条 $F=ma$。
