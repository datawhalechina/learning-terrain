# 第 7 章：思维链：推理轨迹的投影

你看到一个模型输出了一长串文字。

> "首先，我们需要计算总面积……然后减去重叠部分……因此答案是 42。"

你心想：它在推理。它一步一步地思考，从问题走向答案。你看到的是一串文字——token 接 token，逻辑一环扣一环。

但从几何的角度看，你看到的只是**影子**。

真正的推理不是这些文字。真正的推理发生在模型的隐藏状态空间中——那是一组几百维或几千维的向量，在你看不见的地方，沿着一个由训练数据和模型架构共同塑造的向量场，一步一步地流动。你看到的 token——"首先""然后""因此"——只是这条隐藏轨迹在文字空间中的一个离散投影。

思维链不是推理本身。**思维链是推理轨迹的可见投影。**

但"投影"这个词如果只停留在比喻层面，它什么也解释不了。为什么 CoT 训练能提高直接答案的准确率？为什么有些 token 是关键的而有些只是填充？为什么零样本 CoT 有效？要回答这些问题，我们必须把比喻变成几何——先严格定义两个对象，再分析它们之间的关系，最后用定理给出解释。

## 7.1 两类链的形式化定义

在对思维链做任何几何分析之前，我们必须严格区分两个经常被混为一谈的对象。

**定义 1（显式链）**。给定问题 $x$，模型自回归生成的 token 序列 $(x_1, x_2, \ldots, x_T)$ 称为**显式链**。每一步 $x_t$ 是从词汇表 $V$ 中采样的离散符号：

$$x_t \sim p_\theta(\cdot \mid x, x_1, \ldots, x_{t-1})$$

显式链是可见的、可读的、可被人类评估的。它是"思维链"在日常语言中的所指。

**定义 2（隐式链）**。给定同一个问题 $x$ 和同一个模型 $\theta$，隐藏状态序列 $(h_0, h_1, \ldots, h_T)$ 称为**隐式链**。其中 $h_0 = \text{encode}(x)$ 是模型读题后的初始隐藏状态；对于 $t \geq 1$：

$$h_t = \text{Transformer}(h_{t-1}, x_t)$$

即 $h_t$ 是前一步隐藏状态 $h_{t-1}$ 和新生成的 token $x_t$ 经过 Transformer 层后的输出。隐式链是连续的、高维的、人类无法直接阅读的。

**两者的关系**。显式链是隐式链的**离散投影**。在每一步 $t$，隐藏状态 $h_t$ 通过线性映射 $W_{\text{lm}} \in \mathbb{R}^{|V| \times d}$ 和 softmax，被投影到词汇表上：

$$p_\theta(\cdot \mid x, x_{<t}) = \text{softmax}(W_{\text{lm}} h_t)$$

然后从该分布中采样得到 $x_t$。投影矩阵 $W_{\text{lm}}$ 将 $d$ 维连续向量压缩为 $|V|$ 维概率向量——这是一个不可逆的有损操作。大量隐藏状态中的几何信息在这个投影中丢失了。就像一条三维的曲线投在二维纸面上——你只看到了几个离散的点，却看不到点与点之间的连续弯曲。

有了这两个定义，一个自然的追问浮现出来：**隐式链本身是如何运动的？** 它的每一步——$h_t \to h_{t+1}$——遵循什么规律？

## 7.2 隐式链的动力学：欧拉法在隐藏状态空间

把隐式链放在 ch6 的动力系统框架中，一切豁然开朗。$(h_0, h_1, \ldots, h_T)$ 不是一串独立的向量——它是一条**离散轨迹**。每一步的更新恰好是显式欧拉法的形式：

$$h_{t+1} = h_t + F_\theta(h_t, x_{t+1})$$

其中 $F_\theta$ 是 Transformer 层内部的自注意力和 FFN 的复合向量场（含残差连接）。这与 ResNet（ch6, §6.11）和 GPT 自回归（ch6, §6.13）的形式完全一致——只是在思维链的语境下，中间状态 $h_t$ 不是任意的文本生成状态，而是对应着推理的概念阶段。

**性质 1（轨迹连续性）**。$F_\theta$ 关于 $h_t$ 是利普希茨连续的。当步长 $\eta = 1$ 时，轨迹的离散跳跃幅度受限于 $\|F_\theta(h_t, x_{t+1})\|$。小幅度的 $F_\theta$ 意味着隐藏状态在相邻步之间平滑演化——这正是连贯推理的几何特征。大幅度的跳跃——"断裂"——则对应着推理中的逻辑跳跃或错误。

**性质 2（自驱动性）**。$F_\theta(h_t, x_{t+1})$ 依赖于 $x_{t+1}$——即模型**自己选择的 token**。思维链是一个**自驱动**的动力系统：模型在每一步选择一个方向（通过选择 token），然后沿该方向推进。这种"自己推自己"的结构，使思维链比前馈 ResNet 的轨迹更丰富——也更危险：一个错误的选择可能将轨迹推向一个完全错误的吸引子。

这个动力学描述解释了"连贯推理"和"跑题推理"的几何差异——但一个更棘手的问题仍然悬置着。ch7 开篇提到：**CoT 训练之后，即使不输出思维链，直接答案的准确率也提高了**。为什么？

## 7.3 隐式推理：没有 token 的轨迹移动

**定义 3（隐式推理）**。若隐藏状态 $h_t$ 在连续两步之间发生了显著的移动（$\|h_{t+1} - h_t\| > \delta$ 对某个阈值 $\delta$），但这期间生成的 token 是结构性标记（如"因此""所以"——语义内容不包含新推理信息），则称模型在这两步之间进行了**隐式推理**。

隐式推理发生在隐藏状态空间中，但不出现在显式链中。模型在输出"因此答案是"这几个字的短暂间隙中，内部已经完成了一次实质性的信念更新。你看到的文字没有变——但水面下的流动已经改变了方向。

**定理 1（CoT 训练的地形重塑）**。CoT 训练等价于在损失函数 $L(\theta)$ 上叠加一个额外的正则化项——迫使隐藏状态在到达最终答案之前，先经过一系列"概念锚点"。设 $\theta$ 的训练目标为：

$$L_{\text{CoT}}(\theta) = L_{\text{direct}}(\theta) + \lambda \sum_{i=1}^k \ell(h_i, c_i)$$

其中 $\ell(h_i, c_i)$ 是隐藏状态 $h_i$ 与概念锚点 $c_i$ 之间的距离。训练完成后，存在一个正定矩阵 $\Delta H$（由 CoT 训练数据的统计结构决定），使得在正确吸引子 $p^*$ 的邻域内：

$$F_x^{(\text{CoT})}(p) = F_x^{(0)}(p) - \Delta H \cdot (p - p^*) + o(\|p - p^*\|)$$

$\Delta H$ 的加入使得 $p^*$ 处的 Hessian 特征值整体减小——盆地变宽。即使不显式输出 CoT token，向量场 $F_\theta$ 已经被重塑：隐藏状态的流动会自动穿过那些概念节点，最终到达正确答案的盆地。

**这就是 CoT 训练提高直接答案准确率的几何原因**：它不是在教模型"多写几步"——它是在拓宽正确推理路径，使得即使没有中间 token 的引导，轨迹也能自然地流向正确答案。

有了这个解释，下一个问题自然浮现：不是思维链中的每一步都同等重要。有些步骤是关键的推理跃迁，有些只是填充性的修辞。我们能否在不阅读文本的情况下，仅通过隐藏状态的几何特征来区分它们？

## 7.4 推理步的几何分类

**定义 4（推理步的几何分类）**。给定隐藏状态序列 $(h_0, \ldots, h_T)$，定义相邻步之间的**隐藏状态位移** $\Delta h_t = h_t - h_{t-1}$ 和**归一化位移角** $\cos \alpha_t = \langle \Delta h_t, \Delta h_{t-1} \rangle / (\|\Delta h_t\| \|\Delta h_{t-1}\|)$。据此：

- **实质性步**：$\|\Delta h_t\|$ 显著大于平均位移。对应关键推理 token——数字、逻辑转折、新概念引入。
- **结构性步**：$\|\Delta h_t\|$ 接近或小于平均，且 $\cos \alpha_t \approx 1$（方向一致）。对应"首先""然后"等结构性标记——隐藏状态几乎不在移动，token 只是给人类读者的标点。
- **修正步**：$\|\Delta h_t\|$ 较大，且 $\cos \alpha_t < 0$（方向反转）。对应模型"意识到"前一步有误并自我修正。

这种分类不依赖 token 的语义内容——它纯粹基于隐藏状态轨迹的数值特征。你不需要读模型输出的文字，只需要追踪 $\|\Delta h_t\|$ 和 $\cos \alpha_t$ 的时间序列，就能识别思维链中哪些步骤是真正的推理跃迁。

分类之后，一个更深的问题浮现了：**整条轨迹最终会收敛吗？** 收敛到哪里？收敛需要多少步？

## 7.5 思维链的收敛性：永霖极限在推理中的应用

将思维链置于永霖极限（ch5, §5.9）的框架中，收敛不再是一个经验观察——它成为一个定理的结论。

**定理 2（思维链的信念收敛）**。设模型在步骤 $t$ 时，将隐藏状态 $h_t$ 通过 softmax 投影到概率单纯形上，得到信念分布 $p_t = \text{softmax}(W_{\text{lm}} h_t)$。定义能量函数 $E(p_t) = D_{\mathrm{KL}}(p^* \| p_t)$，其中 $p^*$ 是正确答案的分布。若推理算子 $\Phi_\eta$ 满足 ch5 的压缩性条件（$\eta < 2\mu/L^2$），则：

1. 对于能通过 CoT 正确推理的问题，存在唯一不动点 $p^*$，使得从初始信念 $p_0$ 出发，$p_t \to p^*$。
2. 收敛速率至少为线性：$D_{\mathrm{KL}}(p^* \| p_t) \leq k^t D_{\mathrm{KL}}(p^* \| p_0)$，$k = 1 - \eta(2\mu - \eta L^2)/C < 1$。
3. 推理最小步数：$T_{\min} \geq \log(\epsilon / D_0) / \log k$，其中 $D_0 = D_{\mathrm{KL}}(p^*\|p_0)$。

这个定理将 ch5 中的抽象保证变成了对思维链的直接约束。$D_0$ 越大（初始信念离正确答案越远），$T_{\min}$ 越大——但只是对数增长：$D_0$ 翻十倍，步数仅增加约 $-\log_{1/k}(10)$ 步。$k$ 越小（压缩越快，模型越强），步数越少。两者之间存在对数关系——这是压缩映射的指数收敛速度送给思维链的"免费午餐"。

## 7.6 本章小结

思维链是最容易被误解的深度学习现象之一。你看到文字，以为那是推理——但文字只是投影。真正的推理发生在表示空间中的连续曲线 $h_0 \to h_1 \to \cdots \to h_T$ 上。显式链是隐式链的离散投影。隐式推理可以在没有对应 token 的情况下发生。CoT 训练不是教会模型"多写几步"——它是通过重塑推理场的局部几何，拓宽了正确盆地的宽度。永霖极限给出了收敛的形式保证——当压缩性成立时，思维链必然收敛到正确答案，且收敛速率是指数的。

下一章，我们将放大那个引导轨迹的隐形力量——推理场。它是一个遍布信念空间的向量场。正确的答案有宽阔的盆地，错误的答案只有狭窄的裂缝。验证器和 RLHF 如何改造这片场的山川河流？
