# 卷三：推理的几何

前两卷建立了一整套几何语言：空间、地形、梯度、步长、欧拉法、Bregman 散度、KL 几何、动力系统、不动点。

现在，我们要把这整套语言用在一个具体的问题上——可能是深度学习中最让人困惑的问题。

**推理是什么？**

不是"模型输出了正确的答案"。不是"思维链看起来合逻辑"。不是"一步一步思考"。这些是现象，不是定义。

卷三的三章给出了一个几何定义：**推理是隐藏状态在信念空间中沿推理场 $F_x$ 的流动，从初始信念出发，经过若干步欧拉迭代，最终落入某个吸引子的盆地。**

---

第七章拆解了最容易被误解的深度学习现象——思维链。你看到文字，以为那是推理——但文字只是投影。显式链（token 序列）是隐式链（隐藏状态轨迹）在词汇空间中的离散投影。CoT 训练不是在教模型"多写几步"——它是在重塑推理场的局部几何，拓宽了正确盆地的宽度。永霖极限保证：当压缩性成立时，思维链必然收敛。而且隐式推理——没有对应 token 的信念更新——可以在沉默中发生。

第八章放大了引导轨迹的隐形力量——推理场。它是一个遍布信念空间的向量场。每一个问题都在单纯形上布下一张引力之网：正确的答案有宽阔的盆地，错误的答案只有狭窄的裂缝。验证器在错误盆地周围叠加排斥场——填平陷阱。RLHF 重新分配所有不动点之间的能量——不创造新能力，但改变模型偏好哪一个。**你不选择答案。场替你选择。**

第九章解释了为什么有些问题需要两步，有些需要两百步——不是因为"更难"，而是因为信念空间中的某些路段，安全步长 $\eta_{\max}(p)$ 被局部曲率压到了极小。地形决定步伐。训练、规模、温度——所有这些手段本质上都是在**铺沥青**：把崎岖的山路推平，让每一步可以迈得更大。

---

有人问："模型真的在推理吗？"

卷三的回答是：**不要看 token。看轨迹。看场。看不动点。** 推理不是行为——推理是几何。
