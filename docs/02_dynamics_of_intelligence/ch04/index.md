# 第 4 章：行走的方式：优化器与正则化

上一章结束时，我们站在一个矛盾面前。

一方面，我们有了完备的地形语言——损失函数刻画了地面的高低起伏，梯度指明了脚下最陡的斜坡方向，欧拉法把连续下滑变成了离散的步伐，Hessian 帮我们在临界点分辨山谷、鞍点和极小值。我们还看到了 SGD、Momentum 和 Adam 三种截然不同的行走策略——它们在窄谷地形上的轨迹，差异大到几乎不像在走同一片荒野。

另一方面，一个悬而未决的问题仍然笼罩着这一切：**你该如何选择步长？步长要不要随时间变化？更重要的是——你能不能改造这片地形本身？**

荒野徒步者不只是在走路。聪明的徒步者会在悬崖边装上护栏，会在沼泽上铺设木板，会把过于崎岖的山路凿平。他不会只看地图——他会改造地图。

这就是本章的主题。它分为两半：前一半关于**步长**——你怎么选择它，怎么让它随时间变化，怎么让不同的参数维度有不同的步长（这把我们带回 ch3 的优化器，但换一个更深的视角）。后一半关于**正则化**——你怎么直接干预地形本身，把尖锐的悬崖磨平，把过深的裂缝填上，让学习不再只是被动地沿着既有坡度下滑，而是主动地塑造一片更友善的地貌。

## 4.1 你不知道路有多长

继续荒野徒步的比喻。

你被蒙着眼睛空降到荒野中。你只知道脚下的坡度。你决定沿着最陡的下坡方向走。但你面临第一个抉择：**一步迈多大？**

迈得太小——你确实安全。每一步都精确地沿着最速下降方向前进，不会摔跤，不会错过谷底。但太阳快下山了。你的步数有限。在崎岖的高维荒野中，碎步前行可能意味着永远走不到任何一个真正的山谷。

迈得太大——你走得很快。但这片荒野不是光滑的。在你大步跨出的瞬间，地形的曲率可能已经变化了。你可能一脚踩空，从悬崖边摔下去——loss 不再下降，反而急剧上升。或者你跳过了一个狭窄但极深的谷底，停在了一个次优的宽阔盆地中。

所以步长的选择，本质上是一个**连续地形与离散步伐之间的妥协**。在连续的世界里，梯度流 $\frac{d\theta}{dt} = -\nabla L(\theta)$ 是完美的——它沿着光滑的曲线无限逼近极小值。但在离散的世界里，我们只能以有限大小的步伐 $\eta$ 在流形上采样。$\eta$ 越小，离散轨迹越接近连续解；$\eta$ 越大，离散误差越大，直到某个临界点后——离散系统完全失去稳定性，发散到无穷远。

## 4.2 学习率的稳定边界

步长多大才算"太大"？这不是一个经验问题——它有一个严格的数学边界。

考虑一个最简单的二次损失函数：

$$L(\theta) = \frac{\lambda}{2} \theta^2$$

梯度下降的更新为 $\theta_{t+1} = \theta_t - \eta \lambda \theta_t = (1 - \eta \lambda) \theta_t$。这是一个几何级数。收敛的条件是 $|1 - \eta \lambda| < 1$，即：

$$0 < \eta < \frac{2}{\lambda}$$

当 $\eta = 1/\lambda$ 时，一步直达极小值（临界阻尼）。当 $\eta > 2/\lambda$ 时，系统发散——参数的绝对值每一步都在增长，loss 爆炸。

对于一般的非二次损失函数，$\lambda$ 的角色由 Hessian 的最大特征值 $\lambda_{\max}$ 扮演。在最陡峭的方向上，地形的曲率最大，离散化的误差也最大。如果 $\eta > 2 / \lambda_{\max}$，系统在最陡的方向上发散。因此，全局稳定性的必要条件为：

$$\eta < \frac{2}{\lambda_{\max}}$$

但这里有一个悖论。$\lambda_{\max}$ 描述的是地形最陡峭处的曲率。如果你不知道整片地形的 $\lambda_{\max}$（而实践中你几乎从不知道），你怎么保证步长是安全的？

深度学习的实践给出的回答出人意料地简单：**先试一个值，如果 loss 爆炸就减小，如果 loss 下降太慢就增大。** 这种"经验调参"听起来不优雅，但它的有效性背后有一个深刻的几何原因——在极高维的参数空间中，$\lambda_{\max}$ 通常由少数几个非常陡峭的方向贡献。这些方向在训练初期被迅速"征服"（参数沿这些方向快速滑入谷底），之后有效的地形曲率大幅下降，$\eta$ 的安全性也自动提高。

但这引出了另一个问题：**步长应该一直保持不变吗？**

直觉上说，不应该。在训练初期，模型远离极小值，loss 的绝对值大，大步长可以快速接近目标区域。在训练后期，模型在谷底精调，碎步可以避免震荡和过冲。学习率应该**随时间衰减**。

![学习率的稳定边界：收敛与发散](/figures/ch04_learning_rate_stability.svg)

*二次损失 $L = 2\theta^2$（$\lambda=4$，临界步长 $\eta_{\text{crit}} = 2/\lambda = 0.5$）上的梯度下降。左：参数轨迹 — $\eta=0.1$ 缓慢收敛，$\eta=0.3$ 稳定，$\eta=0.5$ 临界阻尼（一步接近零点），$\eta=0.65$ 震荡发散。右：loss 随时间变化（对数坐标）— 步长超过临界值后，loss 不再下降而是指数增长。*

## 4.3 学习率调度：步长的生命周期

学习率调度（learning rate schedule）回答的问题是：$\eta$ 如何随时间 $t$ 变化？

**分段常数衰减（step decay）**。最朴素的策略：每隔若干步，将学习率乘以一个衰减因子 $\gamma < 1$。比如每 30 轮将 $\eta$ 减半。它的优点是简单，缺点是衰减的时机和幅度完全靠经验设定——你不知道地形在哪一刻会需要更小的步伐。

**余弦退火（cosine annealing）**。一个更平滑的方案：让学习率沿着余弦曲线从初始值 $\eta_0$ 衰减到接近零：

$$\eta_t = \eta_{\min} + \frac{\eta_0 - \eta_{\min}}{2} \left(1 + \cos\left(\frac{t}{T}\pi\right)\right)$$

其中 $T$ 是总步数。余弦退火在训练初期缓慢下降（保持大步伐探索），在中期加速下降，在末期平稳着陆。它的几何直觉是：训练前半段，地形的宏观结构最重要——大步伐可以快速穿越高原和浅谷；训练后半段，地形的微观细节才重要——需要小步伐在盆地中精调。

**预热（warmup）**。一个反直觉但至关重要的技巧：在训练的最初几百步中，学习率不是从 $\eta_0$ 开始衰减，而是**从一个极小的值线性增长到 $\eta_0$**。

为什么要预热？因为在训练的最初几步，模型参数是随机初始化的，梯度的方向和大小都极不稳定。直接用大学习率，最初的几步可能把模型推向完全错误的方向——而这个"初始方向偏差"可能无法被后续的梯度步完全纠正。预热给了模型一个"试探期"：先用极小的步伐感受地形的大致结构，建立稳定的梯度统计量（特别是对 Adam 的 $\hat{v}_t$），再加速前进。

**循环学习率（cyclical learning rate）**。另一种激进的策略：不让 $\eta$ 单调衰减，而是让它在一个区间内周期性地上升和下降。大的 $\eta$ 阶段帮助模型逃离鞍点或尖锐极小值，小的 $\eta$ 阶段让模型在当前的盆地中精调。循环学习率利用了 SGD 噪声的一个深层性质：**周期性地提高步长，等价于周期性"加热"系统，帮助它跳出局部陷阱。**

学习率调度本质上是在回答一个问题：**在训练的什么阶段，什么信息对地形探索最重要？** 早期需要全局结构——大步长。后期需要局部精调——小步长。中间需要逃离鞍点——噪声和周期性的大步长。

![学习率调度策略对比](/figures/ch04_lr_schedules.svg)

*四种常见的学习率调度策略。Step decay（左上）：阶梯式衰减，每 N 步将 $\eta$ 减半。Cosine annealing（右上）：沿余弦曲线从 $\eta_0$ 平滑衰减至 $\eta_{\min}$。Warmup + cosine（左下）：前 20 步从极小值线性预热到 $\eta_0$，然后余弦衰减——这已成为 Transformer 训练的标准配置。Cyclical（右下）：$\eta$ 周期性地上升和下降，大 $\eta$ 阶段帮助逃离鞍点，小 $\eta$ 阶段精调。*

## 4.4 正则化：给地形加边界

现在转向本章的另一半。到目前为止，我们一直假设地形是给定的——损失函数由数据和任务决定，模型只能在这片给定的地形上行走。但如果我们能**改造地形本身**呢？

这就是正则化（regularization）的核心思想。它通过在原始损失函数上叠加额外的"惩罚项"，直接改变参数空间的地貌。原本平坦的区域可能被抬高，原本狭窄的谷底可能被拓宽，原本尖锐的裂缝可能被磨平。

**$L_2$ 正则化（权重衰减）**。在原始损失函数上加上参数向量的 $L_2$ 范数平方：

$$L_{\text{total}}(\theta) = L(\theta) + \frac{\lambda}{2} \|\theta\|^2$$

梯度变为 $\nabla L_{\text{total}} = \nabla L + \lambda \theta$。更新公式因此多了一项：

$$\theta_{t+1} = \theta_t - \eta \nabla L(\theta_t) - \eta \lambda \theta_t$$

最后一项 $-\eta \lambda \theta_t$ 在每一步将参数向原点拉回一点——这就是"权重衰减"的名字由来。

$L_2$ 正则化的几何意义是：它在参数空间中叠加了一个以原点为中心的**二次碗**。远离原点的区域被系统性地抬高，参数被"推"向原点附近。这等价于在所有方向上施加了一个均匀的"拉力"，倾向于让参数保持较小的绝对值。在贝叶斯框架下，$L_2$ 正则化等价于给参数施加一个零均值的高斯先验分布。

**$L_1$ 正则化**。使用 $L_1$ 范数而非 $L_2$ 范数：

$$L_{\text{total}}(\theta) = L(\theta) + \lambda \|\theta\|_1 = L(\theta) + \lambda \sum_i |\theta_i|$$

$L_1$ 的梯度是常数（$\text{sign}(\theta_i)$），不依赖于参数大小。这意味着不论参数已经多小，$L_1$ 都以同样的力量将它向零拉。结果是一个著名的性质：**$L_1$ 正则化产生稀疏解**——许多参数被精确地推到零。而在 $L_2$ 中，参数越小，向零拉回的力也越小（梯度是 $\lambda \theta_i$），因此参数倾向于变小但不精确为零。

$L_1$ 和 $L_2$ 的几何差异，在约束优化的视角下最为清晰。将正则化理解为在参数空间中施加一个可行域约束——$L_2$ 对应一个球（圆形约束边界），$L_1$ 对应一个菱形（一个有尖角的约束边界）。损失函数的等高线（椭圆形）与约束边界的切点，就是正则化后的最优解。$L_1$ 的菱形有尖角，损失等高线更容易在坐标轴上与之相切——这正是稀疏性的几何来源。

**弹性网络（Elastic Net）**。$L_1$ 和 $L_2$ 的线性组合：

$$L_{\text{total}}(\theta) = L(\theta) + \lambda_1 \|\theta\|_1 + \frac{\lambda_2}{2} \|\theta\|^2$$

它保留了 $L_1$ 的稀疏性优点，同时用 $L_2$ 的二次项平滑了 $L_1$ 在原点处的不可导问题。在实践中，弹性网络常常比单独的 $L_1$ 或 $L_2$ 更稳定。

![$L_1$ vs $L_2$ 约束几何：稀疏性的来源](/figures/ch04_l1_vs_l2_geometry.svg)

*$L_2$ 正则化（左）：圆形约束区域与椭圆形损失等高线相切。切点处的两个参数都非零——$L_2$ 不产生稀疏性。$L_1$ 正则化（右）：菱形约束区域有尖角。损失等高线更容易在坐标轴（尖角处）与菱形相切——这就是 $L_1$ 产生稀疏解的几何根源：最优解中 $\theta_2 = 0$，参数被精确推到零。X 标记为非正则化的无约束最优解。*

## 4.5 Dropout：随机构造不稳的地形

$L_1$ 和 $L_2$ 在参数空间中直接修改地形。但还有一类正则化方法，不修改损失函数本身，而是**随机地修改模型的结构**——使得模型不能依赖任何单一的特征或路径。

**Dropout** 是最经典的例子。在每次训练迭代中，以概率 $p$ 随机"关闭"一部分神经元（将其激活值设为零）。前向传播使用的是被随机打薄的网络，反向传播也只更新那些幸存的神经元。测试时，所有神经元都激活，但激活值乘以 $1-p$ 以补偿训练时的稀疏性。

Dropout 的几何含义很深。它迫使网络中的每一个神经元都不能依赖其他特定神经元的共存——因为它不知道下次哪些"同事"还在。这驱使网络学习**冗余的、分布式**的表示，而非脆弱的、单点故障式的特征依赖。从地形角度看，Dropout 等价于在每次迭代中使用一个随机扰动后的损失函数——地形在每一步都微微变形。这种持续的扰动倾向于将模型推出尖锐的极小值（它们依赖于精确的权重配置），而引导模型进入更宽、更平坦的盆地（那里即使部分神经元失活，性能也不会崩塌）。

**随机深度（Stochastic Depth）** 是 Dropout 在层级别上的推广：以一定概率随机跳过整个残差块。**DropConnect** 随机屏蔽权重连接而非激活值。所有这些方法的共同主题是：**通过随机注入噪声，防止模型记忆训练数据的精确模式，迫使它学习更一般化的结构。**

## 4.6 数据增强：让地形在数据空间中膨胀

正则化不一定只能在参数空间中施加。另一种思路是：**不改变模型，不改变损失函数，而是改变数据。**

数据增强（data augmentation）通过随机变换训练样本——翻转、旋转、裁剪、颜色抖动、添加噪声——来人为扩张训练集的大小。一张猫的照片水平翻转后依然是猫，但像素值完全不同。模型被要求在这些变换后的样本上表现一致，这等价于在训练过程中注入了一种"不变性先验"：模型学会了对某些变换不敏感。

从地形角度看，数据增强给参数空间中的损失地形增添了一种"平滑效应"。因为模型不能通过精确记忆原始数据的像素位置来降低 loss——同样的语义内容明天可能以镜像或旋转的形式出现——尖锐的、依赖于精确像素配置的极小值被系统性地消除了。平坦的、依赖于语义特征而非像素细节的极小值被保留。

这解释了为什么数据增强和 Dropout 经常协同使用：它们从不同的方向——数据空间和模型结构——共同推动模型走向更平坦、更泛化的区域。

## 4.7 隐式正则化：SGD 噪声的意外礼物

最后，我们来到一个深刻的观察：**你不一定需要显式的正则化。梯度下降本身，特别是随机梯度下降，自带了一种"隐式正则化"。**

回忆 ch3 中关于尖锐和扁平极小值的讨论。全批量梯度下降（full-batch GD）使用全部训练数据计算精确梯度，它的轨迹是确定性的——模型沿着最速下降方向，精确地滑入离初始点最近的那个极小值，无论它是尖锐的还是扁平的。

SGD 不同。mini-batch 的随机性引入了梯度噪声——每一步的方向是精确梯度的无偏估计，但带有方差。这个噪声有一个关键的几何效应：**它在尖锐极小值附近比在扁平极小值附近更容易把模型"踢出去"。**

直觉是这样的。在尖锐极小值处，Hessian 的特征值大，地形曲率高——微小的参数扰动就导致 loss 大幅上升。SGD 的随机梯度噪声恰好提供了这种扰动。噪声的幅度与学习率和 batch size 有关——batch 越小，噪声越大。在尖锐极小值处，噪声很容易超过"逃逸阈值"，把模型推出这个区域。在扁平极小值处，同样的噪声幅度引起的 loss 变化小得多——模型更可能留在那里。

这意味着，即使没有任何显式的 $L_1$ 或 $L_2$ 正则化，SGD 本身就倾向于选择扁平极小值——而扁平极小值往往对应更好的泛化能力。**学习率越大、batch size 越小，这种"噪声驱动的平坦性偏好"越强。**

这也解释了为什么全批量 GD 泛化通常不如 SGD：全批量 GD 没有噪声，它天真地滑入离初始点最近的那个极小值，而不管它是尖锐的还是扁平的。SGD 的噪声像一个"地形滤波器"——它把尖锐的解筛掉了，只留下扁平的解。

这就是隐式正则化。它不是被设计的，而是从随机梯度下降的数学结构中间接涌现的。它提醒我们：**优化器的选择不仅是"走得快还是走得稳"的效率问题——它本质上决定了你会走向什么样的解。**

:::info

**兔狲教授的立场**

社区里有一个顽固的迷信：正则化是"防止过拟合的技巧"。你加 $L_2$，你加 Dropout，你做数据增强——然后你的验证集 loss 就不升了。好像正则化是一种"药"，过拟合是一种"病"。

但从几何的角度看，正则化根本不是"药"。它是**地形改造**。$L_2$ 是在参数空间中叠加了一个以原点为中心的二次碗——它把整个地形往下压，让遥远的区域变得更"昂贵"。Dropout 是在每一步随机地给地形加扰动——它把尖锐的裂缝磨平。数据增强是在数据空间中膨胀地形——它让同样语义内容的无数变体共享同一片低损失区域。

你把这三件事当成三种"技巧"。但它们做的是同一件事：**让平坦的盆地比尖锐的裂缝更容易成为终点。** 平坦性不是正则化的副作用——平坦性是正则化的全部目的。

而 SGD 噪声告诉你一件更深刻的事：**你甚至不需要显式的正则化。** 随机梯度本身就是一个"地形滤波器"——它的噪声在尖锐极小值处比在平坦极小值处更容易把模型踢出去。所以 SGD 天然地偏好平坦解。学习率越大，batch size 越小，这种偏好越强。

你没"加正则化"。你只是选择了一种走路方式——而这种走路方式本身就决定了你会停在什么样的地形上。优化器不是效率工具。优化器是命运。

:::

---

## 4.8 本章小结

本章的主题是"行走的方式"——但它最终走向了一个更深的结论：**行走不只是沿着既有地形下坡。你可以调整步长的节奏（学习率调度），你可以改造脚下的地形（正则化），你甚至可以利用行走本身带来的随机噪声来筛选更好的目的地（隐式正则化）。**

学习率是步长——它必须小于 $2 / \lambda_{\max}$ 才能稳定，而调度策略（分段衰减、余弦退火、预热、循环）让步伐随训练的进展而适应。$L_1$ 和 $L_2$ 正则化直接在参数空间中叠加约束——前者产生稀疏性（菱形与椭圆相切于坐标轴），后者均匀收缩所有参数。Dropout 和数据增强从两个不同方向注入随机性，推动模型离开脆弱的尖锐极小值，进入宽厚的平坦盆地。而 SGD 的隐式正则化——梯度噪声天然地偏好平坦解的倾向——揭示了优化和泛化之间最深层的联系：**你怎么走，决定了你走到哪里。**

下一章，我们将离开欧几里得世界，进入非欧几里得的信念空间。Bregman 散度和 KL 散度——这些不对称的、非传统的"距离"——将重新定义什么是"近"和"远"。在那里，走路的方式会再次被颠覆。

## 悬而未决的问题

1. 学习率的稳定条件 $\eta < 2 / \lambda_{\max}$ 依赖于 Hessian 的最大特征值。在深度网络的训练过程中，$\lambda_{\max}$ 本身是动态变化的。我们能否在训练过程中实时估计 $\lambda_{\max}$，并动态调整 $\eta$ 以始终保持稳定？

2. 余弦退火、预热和循环学习率在实践中广泛使用，但它们各自的最优参数（周期长度、预热步数、上下界）几乎总是通过试错确定。是否存在一种基于地形几何（如 Hessian 特征谱的演化）的自动化调度策略？

3. $L_1$ 正则化的稀疏性来自菱形约束边界与损失等高线在坐标轴上的相切——但这需要损失等高线恰好"碰到"尖角。在高维空间中，这种相遇的概率有多大？是否存在不产生稀疏性的 $L_1$ 正则化失效场景？

4. Dropout 的"随机打薄网络"在训练时引入了噪声，但测试时却使用完整网络（乘以 $1-p$）。这种训练-测试的不对称性是否在参数空间中产生了一个系统性的偏差？" inverted dropout" 的训练-测试等价性是否完全消除了这个偏差？

5. 数据增强构造了一个"不变性先验"——模型学会了对某些变换不敏感。但如果我们增强的方式包含了不该有的不变性（比如对手写数字做垂直翻转，6 和 9 就会混淆），增强是否反而损害了泛化？

6. SGD 噪声倾向于选择扁平极小值——这是相关关系还是因果关系？是否可能存在一个尖锐但泛化仍然好的极小值，其泛化能力来自某种与 Hessian 曲率无关的其他几何性质？

7. 不同的优化器（SGD vs Adam vs AdamW）对隐式正则化的依赖程度不同——Adam 的自适应步长改变了噪声结构。这是否部分解释了为什么 Adam 在某些任务（如语言建模）上泛化不如精心调参的 SGD？

8. 如果隐式正则化的强度取决于学习率和 batch size，那么"学习率越大泛化越好"是否有一个上限？在什么条件下，学习率过大会从"有益的噪声"变成"有害的震荡"？

9. 权重衰减（$L_2$ 正则化）在 Adam 中不等价于传统的 $L_2$ 正则化——因为 Adam 的自适应步长改变了权重衰减的有效幅度。AdamW 的解耦权重衰减修复了这个问题。这种解耦是否能推广到其他自适应优化器（如 RMSprop、AdaGrad）？

10. 正则化本质上是引入先验知识——$L_2$ 引入"参数应该小"的先验，数据增强引入"语义在变换下不变"的先验。在什么意义上，这些先验是在"帮助"模型，而非"限制"模型？是否存在一种正则化，它只消除有害的过拟合，而不限制模型学习真正有用的模式？

11. 循环学习率的"周期性加热"能否被理解为一种模拟退火（simulated annealing）——通过周期性提高温度（大学习率）来帮助系统逃离局部极小值？如果是，那么最优的"温度曲线"应该是什么样的？

12. 如果不同优化器的隐式正则化效果不同，那么"模型合并"（将两个用不同优化器训练的模型加权平均）是否等价于某种更复杂的正则化策略？它能否结合两个优化器的各自优势？

---

**本章留下的核心问题是：**

**如果行走的方式——步长、动量、噪声、正则化——都系统性地改变了最终到达的极小值的性质，那么我们是否应该把"优化器的选择"看作一种先验，而非一种纯粹的技术决策？**

:::info

**走路不只是沿着坡度下降。** 你可以改变步幅的节奏（学习率调度），可以在悬崖边装上护栏（正则化），可以利用脚步的随机晃动来筛选更稳的落脚点（隐式正则化）。学会走路之后，下一步是学会辨认脚下的路：欧几里得距离不是唯一的距离度量。在信念空间中，从确信到混乱，和从混乱到确信——这两条路的长度完全不同。下一章，我们将进入非欧几里得世界：Bregman 散度与 KL 散度。

:::
