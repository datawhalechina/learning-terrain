# 卷二：行走与信念

卷一结束时，你站在一片荒野中。你知道脚下的地形有坡度——损失函数画出了山川和盆地。你知道身体在参数空间中——每一步梯度更新都在移动模型。你也知道视野在表示空间中——身体的位置决定了模型如何理解世界。

但你还有一个问题没问：**这片荒野本身，是平的吗？**

你以为是。因为你习惯用欧几里得的眼睛看世界。两点之间直线最短。步长就是 $\eta$。距离就是 $\sqrt{\sum (a_i - b_i)^2}$。

卷二的三章要告诉你：**你脚下的空间不是平的。** 而且"不是平的"这三个字，不是哲学修辞——它有严格的形式化，有定理，有证明，有从信息几何到动力系统到不动点的完整数学链。

---

第四章从最实际的问题开始：**走路的方式重要吗？** 答案是：极其重要。步长多大才安全？要不要带惯性？要不要根据地形自动调整步伐？SGD、Momentum、Adam——它们不是"不同的优化器"，它们是同一片荒野上的不同行走策略。正则化不是在"防止过拟合"——它是在改造地形本身。而 SGD 的随机噪声告诉你一件更深刻的事：你怎么走，决定了你走到哪里。

第五章是全书数学的第一个高峰。乌鸦飞直线——那是欧几里得的语言。水沿能量地形流动——那是 Bregman 的语言。在信念空间中，两个概率分布之间的"距离"不是对称的——从确信到混乱和从混乱到确信，代价完全不同。KL 散度是信念空间中自然的"能量差"。永霖极限证明：只要步长不超过切空间曲率规定的上限，欧拉步推理就必然收敛——不是“通常如此”，是几何强制的。

第六章是卷二的终章，也是全书数学深度最集中的一章。它将动力系统的整套语言——相空间、轨迹、不动点、李雅普诺夫函数、吸引子、分岔——映射到深度学习的核心架构上。ResNet = 显式欧拉法。GPT 自回归 = 隐状态空间的欧拉迭代。DEQ = 不动点求解。信念不动点 = KL 凝固判据。四张面孔，一个灵魂：**动力系统沿能量下降的方向演化，直到向量场消失——不动点。**

---

卷一让你看见了地形。卷二让你学会了在弯曲的地形上行走——并且证明了，只要你走在正确的几何中，你一定会走到终点。

但终点是什么？你怎么知道你到了？卷三——推理的几何——即将回答。
