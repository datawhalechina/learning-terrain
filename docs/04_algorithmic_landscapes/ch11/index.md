# 第 11 章：深度架构的几何

上一章我们看了六个经典算法。它们有一个共同点：**运作在平坦的欧几里得空间中。** 线性回归的椭圆碗是二次型。PCA 的数据云是高斯椭球。SVM 的超平面是线性的。它们的几何是清晰、优雅、可解析的。

这一章，我们进入深度架构。在这里，空间不再是平坦的。Attention 在 token 之间建立了**软的、数据依赖的几何连接**——不是固定的距离，而是根据内容动态变化的引力。LoRA 在参数空间中划出了一个**低秩子空间**——模型在这个子空间中移动，而不是在整个高维参数空间中自由漫步。

这两个架构代表了深度学习的两个核心几何操作：**弯曲表示空间**（Attention）和**约束参数运动**（LoRA）。理解它们的几何，就是理解现代深度架构的设计语言。

![Attention：QKV三轴几何](/figures/ch11_attention_qkv.svg)

*Q（橙）、K（蓝）、V（绿）三轴定义了注意力在表示空间中的投影几何。Query和Key向量在Q-K平面上的内积（$QK^T$）决定了相似度——虚线连接每个Query与其最匹配的Key。Value向量沿V轴编码被"注意"的内容。三者的投影矩阵在训练中学习到的是token之间的马氏度量。*

## 11.1 Attention：Token 之间的软几何连接

自注意力是 Transformer 的心脏。它的公式——query、key、value——已经被背过无数次：

$$\text{Attention}(Q, K, V) = \text{softmax}\left(\frac{QK^T}{\sqrt{d_k}}\right) V$$

但公式背后的几何是什么？

将 $Q, K, V$ 看作从同一个输入序列 $X$ 通过三个不同的线性投影产生的三个"视角"。$Q$（Query）在问："我应该注意谁？"$K$（Key）在说："我有这些特征，你感兴趣吗？"两者的内积 $QK^T$ 在度量 Query 和 Key 在投影空间中的**余弦相似度**——方向越一致，注意力越强。

除以 $\sqrt{d_k}$ 是为了防止内积的方差随维度增长而爆炸——这是高维空间中随机向量几乎正交的自然结果（ch2, §2.4）。然后 softmax 将相似度转换为概率分布——每个 token 对其他 token 的注意力权重。

最后，$V$（Value）提供被"注意"的内容。注意力权重将 $V$ 的行加权平均——每个 token 的新表示是所有 token 的 Value 的**注意力加权组合**。

几何视角：**Attention 在 token 之间建立了一个完全连通的、加权的、数据依赖的有向图。** Token 是节点。注意力权重是边的强度——从 Query token 指向 Key token。这个图在每一层、每一个注意力头上都被重新计算。$Q, K, V$ 的投影矩阵——$W_Q, W_K, W_V$——定义了图中的"度量"：它们决定了哪些 token 在投影空间中彼此靠近。

![多头注意力：并行子空间](/figures/ch11_multihead_subspaces.svg)

*三个注意力头在三个不同的投影子空间中并行运算。Head 1（橙，句法）弯曲空间以捕捉主谓关系。Head 2（绿，语义）捕捉同义/反义关系。Head 3（红，位置）捕捉相邻token的局部依赖。每个头是一个独立的几何"视角"，$W_O$ 在最后将所有视角融合。*

## 11.2 多头注意力：并行几何投影

一个注意力头只提供一个视角。Transformer 使用**多头注意力**——$h$ 个独立的注意力头并行工作，每个头有自己的一套 $Q, K, V$ 投影。

$$\text{MultiHead}(X) = \text{Concat}(\text{head}_1, \ldots, \text{head}_h) W_O$$

其中 $\text{head}_i = \text{Attention}(XW_Q^i, XW_K^i, XW_V^i)$。

几何视角：每个注意力头在表示空间中定义了一个**不同的子空间**。头 1 可能关注句法关系——主语和谓语之间的连接。头 2 可能关注语义关系——同义词和反义词。头 3 可能关注位置关系——相邻 token 之间的局部依赖。

这些子空间是 $W_Q, W_K, W_V$ 的列空间——每个投影矩阵将 $d_{\text{model}}$ 维的输入映射到 $d_k$ 或 $d_v$ 维的子空间（通常 $d_k = d_v = d_{\text{model}} / h$）。$h$ 个头同时在 $h$ 个不同的子空间中计算注意力，然后将结果拼接起来。这等价于在不同的几何"视角"下并行地分析同一组 token，然后将多视角信息融合。

$W_O$ 在最后将拼接的多头输出映射回 $d_{\text{model}}$ 维——这是一个"融合"操作，将不同子空间的信息重新整合进统一的表示空间。

## 11.3 注意力作为学习的度量

将注意力的几何推向更深一层：**$QK^T$ 定义的不是固定的欧几里得内积——而是一个在训练过程中被学习的、数据依赖的"相似度度量"。**

在欧几里得空间中，两个向量的相似度是 $\langle x, y \rangle = x^T y$。在注意力中，$x$ 和 $y$ 首先被投影到 Query 和 Key 空间：$Qx$ 和 $Ky$。两者在投影空间中的内积是：

$$(Qx)^T (Ky) = x^T (Q^T K) y$$

矩阵 $Q^T K \in \mathbb{R}^{d_{\text{model}} \times d_{\text{model}}}$ 定义了一个**马氏度量**——一个在原始空间中弯曲了"相似度"概念的二次型。如果 $Q^T K$ 是单位矩阵，我们就回到了标准的欧几里得内积。但 $Q$ 和 $K$ 在训练中被不断调整——模型在**学习**一个度量，而不是使用预设的度量。

这就是注意力与 ch5 中 Bregman 散度的深层联系。Bregman 散度说：在概率空间中，自然的"距离"不是欧几里得的——它是 KL 散度。注意力说：在 token 关系空间中，自然的"相似度"不是欧几里得内积——它是 $Q$ 和 $K$ 学习到的投影内积。两者都是**放弃预设的平直度量，转而使用数据塑造的弯曲度量。**

![LoRA：低秩因子分解](/figures/ch11_lora_factors.svg)

*左：$A \in \mathbb{R}^{d \times r}$（橙色热图），$d=24$，$r=4$。右：$B \in \mathbb{R}^{r \times d}$（蓝色热图）。两者的乘积 $AB$ 是一个秩至多为 $r$ 的矩阵——它定义了参数更新所在的低秩子空间。*

![LoRA更新热图](/figures/ch11_lora_heatmap.svg)

*$\Delta W = AB$ 的完整热图。红/蓝色块表示正/负权重变化。尽管 $d \times d = 576$ 个元素，但矩阵的秩仅为 $r=4$——绝大多数"自由度"被约束在低秩结构中。这就是LoRA高效的原因。*

## 11.4 LoRA：低秩子空间中的参数运动

从一个完全不同的方向，LoRA（Low-Rank Adaptation）也讲述了一个关于几何和约束的故事。

微调一个大模型——将它在特定任务上进一步训练——通常需要更新全部参数。对于一个 70B 参数的模型，这意味着要存储和优化 70B 个梯度。LoRA 的洞见是：**微调时的参数更新矩阵是严重低秩的。** 你不需要更新整个 $W \in \mathbb{R}^{d \times d}$——你只需要更新两个小矩阵 $A \in \mathbb{R}^{d \times r}$ 和 $B \in \mathbb{R}^{r \times d}$，其中 $r \ll d$（通常 $r = 8$ 或 $16$）：

$$W' = W + \frac{\alpha}{r} \cdot AB$$

$A$ 和 $B$ 的乘积 $AB \in \mathbb{R}^{d \times d}$ 是一个秩至多为 $r$ 的矩阵。它在 $W$ 的参数空间中定义了一个**低秩子空间**——微调时的参数更新只能在这个子空间中移动。

几何视角：全参数微调允许模型在完整的 $\mathbb{R}^{d^2}$ 参数空间中自由移动——从一个预训练极小值走向任何方向。LoRA 将这种自由限制在了一个 $r(d + d) \ll d^2$ 维的子空间中。这个子空间不是随意选的——它由 $A$ 和 $B$ 在微调过程中学习到。$A$ 的列定义了"运动的主要方向"，$B$ 的行定义了这些方向的"权重组合"。

这个约束不是限制——它是**隐式正则化**（ch4, §4.7）。它将参数更新限制在了一个低维流形上，防止模型在微调数据上过拟合，同时保留了预训练学到的知识结构。

## 11.5 为什么 LoRA 有效？内在维度假说

LoRA 有效的原因指向了一个更深刻的几何事实：**任务适配的"内在维度"远小于参数空间的维度。**

对于大多数下游任务——情感分类、摘要生成、代码补全——将模型从通用预训练状态适配到特定任务，只需要在参数空间中沿着少数几个方向移动。这些方向跨越了一个低维子空间——它的维度可能是几百或几千，而不是几十亿。

这与 ch9 中"涌现深度"的逻辑完全一致：**地形决定了需要多少维度的运动。** 简单的地形适配——微调到与预训练高度相似的任务——只需要在几个方向上微调。复杂的地形适配——微调到与预训练完全不同的领域——可能需要更多的方向。LoRA 的秩 $r$ 是一个**几何预算**：为地形适配分配多少个独立的参数运动方向。

这也解释了为什么 LoRA 的 $r$ 不需要很大——在许多任务中 $r=8$ 就足够了。不是因为"8 个方向总是够了"，而是因为大多数微调任务的地形足够平滑，只需要 8 个独立的方向来从预训练的盆地走到任务特定的盆地。

## 11.6 注意力 + LoRA：弯曲与约束的统一

将注意力（11.1-11.3）和 LoRA（11.4-11.5）放在一起，我们看到了一幅统一的几何图景。

注意力在**表示空间**中操作——它弯曲了 token 之间的相似度度量，建立了动态的、数据依赖的几何连接。LoRA 在**参数空间**中操作——它约束了参数更新的方向，将微调限制在一个低秩子空间中。

两者分别对应了本书的两个核心空间（ch2）：注意力改造了**视野**——模型如何"看见"token 之间的关系。LoRA 约束了**身体**——模型在适应新任务时身体能向哪些方向移动。

它们的组合——Transformer + LoRA 微调——是现代深度学习中最常见的范式：用注意力在表示空间中建立丰富的几何结构，用 LoRA 在参数空间中做高效的、受约束的适配。这正是 ch2 中"身体与视野"配对在工程实践中的精确对应。

## 11.7 本章小结

深度架构的几何不同于经典算法的几何。它不是平坦的椭圆碗或 Voronoi 图——它是弯曲的、动态的、数据依赖的。

注意力在 token 之间建立了软的几何连接——$QK^T$ 定义的不是固定的欧几里得内积，而是一个被训练数据塑造的马氏度量。多头注意力在多个并行的子空间中同时计算这些连接。LoRA 在参数空间中划出一个低秩子空间——将微调时的参数运动限制在少数几个方向内，利用的是"任务适配的内在维度远小于参数空间维度"这个几何事实。

注意力弯曲了视野。LoRA 约束了身体。两者共同构成了现代深度架构的几何设计语言。

## 悬而未决的问题

1. $QK^T$ 定义了一个马氏度量——但 $Q$ 和 $K$ 是独立学习的，$Q^TK$ 不一定对称。不对称的度量在几何上意味着什么？"从 A 到 B 的相似度不等于从 B 到 A 的相似度"——这与 KL 散度的不对称性有内在联系吗？

2. 多头注意力在不同的子空间中运作。这些子空间是否在训练过程中自发地"分工"——有的专攻句法，有的专攻语义？还是这种分工只是人类的事后解释？

3. 注意力权重矩阵是一个随机矩阵（每行求和为 1）。它的谱（特征值分布）在训练过程中如何演化？是否随着训练推进，注意力变得更"聚焦"（更少的非零特征值）？

4. LoRA 假设微调更新是低秩的——但秩 $r$ 的最优值是否依赖于任务与预训练数据之间的"距离"？如何在微调前估计所需的秩？

5. LoRA 的参数更新被限制在一个低秩子空间中——这与 ch4 中正则化的精神一致（约束参数运动的方向）。LoRA 是否可以被理解为一种"数据自适应的正则化"——子空间本身是在微调数据上学到的？

6. 注意力的 softmax 在输出一个概率分布——这与 ch5 中单纯形上的 softmax 投影完全一致。注意力是否可以在信念空间（ch8）的框架下被重新解释——每个注意力头在问题 $x$ 的推理场 $F_x$ 中定义一个"局部向量场"？

7. 在 LoRA 中，为什么 $A$ 通常用高斯初始化而 $B$ 为零？这种初始化在参数空间中对应着什么几何位置——微调从预训练的不动点出发，只沿 $A$ 的列方向探索？

8. Transformer 的层数是预设的（ch6 中的"预设深度"）。是否存在一种"自适应深度 Transformer"——每一层动态决定是否需要额外的注意力迭代，类似 DEQ 的涌现深度？

9. 注意力中的 $1/\sqrt{d_k}$ 缩放是对高维空间随机向量正交性的修正。如果不做这个缩放，softmax 会饱和——退化为 one-hot 注意力（只关注一个 token）。这种饱和在几何上对应着什么——注意力场的"坍缩"吗？

10. LoRA 在不同的 Transformer 层上是否应该使用不同的秩 $r$？底层的表示更"通用"——秩应该更小？顶层的表示更"任务特定"——秩应该更大？

11. 多头注意力和 LoRA 是否可以统一——每个注意力头的 $Q, K, V$ 投影被限制在低秩子空间中微调，而这个子空间正是该头最敏感的"几何方向"？

12. 注意力弯曲了表示空间，LoRA 约束了参数空间。是否存在一个统一的数学框架——某种"注意力的参数空间对偶"——将两者放在同一个几何语言中描述？

---

**本章留下的核心问题是：**

**注意力学到了一个弯曲的度量，LoRA 发现了一个低秩的运动子空间——两者都是在高维空间中寻找低维结构。是否存在一个统一的几何原理，解释为什么深度架构中几乎所有有效的操作——注意力、LoRA、残差连接、层归一化——都与"降维"或"约束维度"有关？**
