# 卷四：算法的地貌学

你学过的每一个公式，都是一片地形的等高线。

线性回归的 $\hat{\beta} = (X^TX)^{-1}X^Ty$——你以为它是代数推导。它不是。它是一只椭圆碗的底部坐标。PCA 的特征向量——你以为它是协方差矩阵分解的结果。它不是。它是数据云最长轴的方向。SVM 的最大间隔——你以为它是约束优化的对偶解。它不是。它是两类数据之间最宽的那条空缝。

卷四的三章，是把你在前九章学到的全部几何语言，用回到你最熟悉的算法上——然后你会发现，你从未真正看见过它们。

---

第十章重新审视六个经典算法——线性回归、逻辑回归、PCA、SVD、SVM、K-means。每一个你背过的公式，背后都是一个几何对象。线性回归在椭圆碗上滑到底。PCA 找数据云最长的轴。SVM 在两团数据之间劈开最宽的空隙。K-means 把空间切成 Voronoi 镶嵌。六种算法，六种不同的数学形式——同一个灵魂：**在一个空间中，沿着某个几何量的梯度，走向某个极值的位置。**

第十一章进入深度架构。经典算法运作在平坦的欧几里得空间中。深度架构弯曲了空间本身。Attention 不是"计算注意力权重"——$Q^T K$ 定义了一个在训练中被学习的马氏度量。每个 token 之间的"相似度"不是被发现的——是被反向传播雕刻出来的。LoRA 不是"省显存的技巧"——它揭示了一个你不愿承认的几何事实：适配一个新任务，只需要沿 8 个低秩方向移动。你花几百万训练的 1750 亿参数，绝大多数是在维护地形的光滑性。

第十二章——全书的终点。扩散模型。前向：结构溶解为噪声（熵增）。逆向：噪声收敛到结构（熵减）。得分函数是数据空间中的向量场——它指向"更多数据的方向"。逆扩散是这个向量场中的欧拉步轨迹。生成是轨迹收敛到数据流形。**337 年。从 $F=ma$ 到扩散模型。同一条弧线：力 → 能量 → 地形 → 运动 → 不动点 → 结构。**

---

卷四不是"应用"。卷四是**回家**。你走了九章的路，建立了一整套几何语言。现在，用这套语言重新看你以为你懂的每一个算法——你会发现它们从未如此清晰。
