# 第 10 章：经典算法的几何

你学过线性回归。你学过 PCA。你学过 SVM。

但你是用公式理解它们的——$\hat{\beta} = (X^TX)^{-1}X^Ty$，$\max \frac{2}{\|w\|}$，$\text{tr}(W^T C W)$。你记得这些公式，你能推导它们，你在考试中正确地使用它们。

但你从未**看见**它们。

线性回归的闭式解——你把它当成一个代数结果。但它其实是一个几何事实：你在一只椭圆碗的底部。PCA 的协方差矩阵分解——你把它当成一个线性代数练习。但它其实是一个几何事实：你找到了数据云最长的轴。SVM 的最大间隔——你把它当成一个约束优化问题。但它其实是一个几何事实：你在两类数据之间找到了一条最宽的空隙。

卷四的三章，就是要把这些"代数公式"转化为"几何直觉"。这一章从最经典的算法开始——线性回归、逻辑回归、PCA、SVD、SVM、K-means。下一章进入深度架构——Attention 和 LoRA。最后一章来到扩散模型——噪声如何变成结构，为全书收束。

## 10.1 线性回归：椭圆碗的底部

线性回归是最简单的学习问题——但它已经包含了几何的全部要素。

给定数据矩阵 $X \in \mathbb{R}^{n \times d}$ 和标签向量 $y \in \mathbb{R}^n$，我们要找到权重 $\theta \in \mathbb{R}^d$ 使得预测 $\hat{y} = X\theta$ 尽可能接近 $y$。最小化均方误差：

$$L(\theta) = \frac{1}{n} \|y - X\theta\|^2$$

展开二次型：$L(\theta) = \frac{1}{n}(\theta^T X^T X \theta - 2y^T X \theta + y^T y)$。这是一个关于 $\theta$ 的完美二次函数——不包含任何高阶项。$L(\theta)$ 在参数空间中定义了一个**椭圆碗**。

碗的形状由 $X^T X$（Hessian）决定。$X^T X$ 的特征值给出了碗在不同方向上的曲率。大特征值对应陡峭的方向——沿这些方向，梯度大，收敛快。小特征值对应平缓的方向——沿这些方向，梯度小，收敛慢。

碗的底部——全局极小值——有一个优雅的闭式解：$\theta^* = (X^T X)^{-1} X^T y$。从几何视角看，这个公式不是"代数推导"——它是**碗的梯度为零的位置**。设 $\nabla L(\theta) = \frac{2}{n} X^T (X\theta - y) = 0$，直接解出 $\theta^*$。

在这个椭圆碗上做梯度下降，是一个完美的指数收敛过程。从任意初始点 $\theta_0$ 出发，每步的误差以固定的比例衰减：

$$\|\theta_t - \theta^*\| \leq (1 - \eta \lambda_{\min})^t \|\theta_0 - \theta^*\|$$

其中 $\lambda_{\min}$ 是 $X^T X$ 的最小特征值。这是 ch3 中 $L$-光滑和 $\mu$-强凸的最纯粹实例——整个地形是一个均匀弯曲的碗，没有鞍点，没有局部极小值，没有高原。线性回归之所以"简单"，不是因为参数少——而是因为它的损失地形是一个完美的椭圆碗。

## 10.2 逻辑回归：概率曲面上的分离边界

从回归走向分类，损失函数从 MSE 变成了交叉熵。地形从椭圆碗变成了一个更微妙的对象。

逻辑回归将线性输出 $X\theta$ 通过 sigmoid 函数 $\sigma(z) = 1/(1 + e^{-z})$ 映射为概率。损失是交叉熵：

$$L(\theta) = -\frac{1}{n} \sum_{i=1}^n \left[ y_i \log \sigma(x_i^T \theta) + (1-y_i) \log(1 - \sigma(x_i^T \theta)) \right]$$

与线性回归的关键几何差异：**逻辑回归的损失函数仍然是凸的——但它不是二次的。** 它的 Hessian 不是常数矩阵——它依赖于当前位置 $\theta$。在数据点密集的区域，曲率大——地形陡峭。在数据点稀疏的区域，曲率小——地形平缓。

sigmoid 函数在输出空间中创造了一个**概率曲面**。$\theta^T x = 0$ 定义了决策边界——一个 $d-1$ 维的超平面。在这个超平面上，模型输出概率 0.5——完全不确定。超平面的一侧，概率趋近于 1；另一侧，概率趋近于 0。sigmoid 的陡峭程度由 $\theta$ 的模长控制——$\|\theta\|$ 越大，过渡越陡，决策边界越"硬"。

这使得逻辑回归的地形具有一种自适应的曲率：在决策边界附近，损失对参数变化极度敏感——一小步就可能翻转预测。远离决策边界处，损失对参数变化几乎不敏感——预测已经"饱和"了。这是线性回归的均匀椭圆碗所不具备的几何丰富性。

![PCA：数据云的主轴](/figures/ch10_pca_ellipsoid.svg)

*二维数据云及其协方差椭圆。两个主成分沿方差最大方向对齐。第一主成分（橙）捕获最大方差，第二主成分（蓝）与之正交。*

## 10.3 PCA：数据云的主轴

PCA 不涉及任何损失函数或标签。它是纯粹的**无监督几何**——只关心数据本身的形状。

给定数据中心化后的矩阵 $X \in \mathbb{R}^{n \times d}$，PCA 寻找一组正交方向 $v_1, v_2, \ldots, v_k$，使得数据在这些方向上的投影方差最大。等价地，PCA 寻找数据协方差矩阵 $C = \frac{1}{n} X^T X$ 的前 $k$ 个特征向量。

几何直觉：数据点在高维空间中形成了一个**数据云**。这个云大致是椭圆形的。PCA 找到这个椭圆的**主轴**——最长的轴（第一主成分）、次长的轴（第二主成分），以此类推。每个主轴的方向由 $C$ 的一个特征向量给出，该轴的长度（方差）由对应的特征值给出。

在参数空间的几何语言中，PCA 等价于：用一个低维的超平面去逼近高维的数据云，使得投影后的方差最大。这个超平面的法向量是被丢弃的方向。从信息几何的角度看，PCA 在欧几里得空间中做了 KL 散度在概率空间中做的事——找到了"变化最大的方向"。

PCA 是最简单的表示学习。它不涉及非线性、不涉及标签、不涉及梯度下降——但它的几何精髓贯穿了本书的每一章：**找到空间中变化最大的方向，沿着这些方向压缩数据，保留最重要的结构，丢弃冗余的维度。**

![SVD：矩阵的地形分解](/figures/ch10_svd_decomposition.svg)

*任意矩阵 $A$ 的作用分解为三步：$V^T$ 旋转单位圆 → $\Sigma$ 沿坐标轴缩放 → $U$ 再次旋转。奇异值谱的衰减速度决定了矩阵的"有效秩"——LoRA（ch11）正是利用了这一事实。*

## 10.4 SVD：矩阵的地形分解

PCA 是 SVD 的一个特例。但 SVD 本身拥有更丰富、更独立的几何含义。

任意矩阵 $A \in \mathbb{R}^{m \times n}$ 可以被分解为三个矩阵的乘积：

$$A = U \Sigma V^T$$

- $U \in \mathbb{R}^{m \times m}$：左奇异向量——$A$ 的列空间的一组正交基。它们是 $AA^T$ 的特征向量。
- $\Sigma \in \mathbb{R}^{m \times n}$：对角矩阵，对角线上是奇异值 $\sigma_1 \geq \sigma_2 \geq \cdots \geq 0$。奇异值是 $A$ 在各个方向上的"缩放因子"。
- $V^T \in \mathbb{R}^{n \times n}$：右奇异向量——$A$ 的行空间的一组正交基。它们是 $A^T A$ 的特征向量。

几何解读：任意矩阵 $A$ 的作用——将一个向量 $x$ 映射为 $Ax$——可以分解为三步：$V^T$ 旋转坐标系，$\Sigma$ 沿新坐标轴缩放，$U$ 再次旋转。**任何线性变换，本质上都只是一组旋转和缩放。**

奇异值的**谱**——$\sigma_1, \sigma_2, \ldots$——是矩阵 $A$ 的核心几何特征。奇异值衰减的速度决定了 $A$ 的"有效秩"——有多少个独立的、非零的缩放方向。在深度学习中，权重矩阵的奇异值谱决定了该层变换的"信息容量"。LoRA（ch11）正是利用了这个事实：微调时的参数更新矩阵是严重低秩的——它的奇异值谱在几个大值之后迅速衰减到零。

![SVM：最大间隔几何](/figures/ch10_svm_margin.svg)

*两类数据之间的最大间隔超平面。虚线标记间隔边界。圆圈标记支持向量——唯一决定超平面位置的点。绿色带为间隔区域。*

## 10.5 SVM：最大间隔的几何

SVM 寻找一个超平面将两类数据分开——但不是随便哪个超平面。它寻找**最大间隔**超平面——距离最近的数据点（支持向量）最远的那个。

形式化地，对于线性可分的数据，SVM 求解：

$$\min_{w, b} \frac{1}{2} \|w\|^2 \quad \text{s.t.} \quad y_i (w^T x_i + b) \geq 1, \forall i$$

目标是最小化 $\|w\|^2$——这等价于最大化间隔 $2/\|w\|$。约束确保每个点都被正确分类且离超平面至少距离 $1/\|w\|$。

几何视角：两类数据点在空间中形成两团云。SVM 找到的超平面是两团云之间**最宽的空隙**——一个没有任何数据点的带状区域的中线。支撑这个空隙边界的数据点就是**支持向量**——它们是最接近超平面的点，也是唯一决定超平面位置的点。所有其他点——无论你如何移动它们，只要不越过空隙——都不影响解。

SVM 是约束优化在几何中最优美的体现。它将一个分类问题变成了一个**几何间隙最大化**问题。在深度学习中，这个"最大间隔"思想以各种形式复现——对比学习中的温度参数控制着表示空间中正负样本之间的"间隙"，三元组损失显式地要求锚点与正样本的距离小于与负样本的距离加一个 margin。

![K-means：Voronoi镶嵌](/figures/ch10_kmeans_voronoi.svg)

*四个质心（菱形）将空间分割为 Voronoi 区域。边界是相邻质心连线的垂直平分线。不同初始化对应不同的镶嵌方式——不同局部极小值。*

## 10.6 K-means：空间分割的几何

K-means 是最朴素的聚类算法。给定 $n$ 个数据点和预设的聚类数 $K$，K-means 交替执行两步：将每个点分配给最近的质心；将每个质心更新为其分配点的均值。

几何视角：K-means 在数据空间中进行了一次**Voronoi 镶嵌**。每个质心 $\mu_k$ 定义了一个 Voronoi 区域——所有更靠近 $\mu_k$ 而非其他质心的点的集合。区域之间的边界是相邻质心连线的**垂直平分线**（在高维空间中是垂直平分超平面）。

K-means 的损失函数——类内平方和——在质心位置上是非凸的。它有许多局部极小值，对应着不同的镶嵌方式。这就是为什么 K-means 的结果依赖于初始化——不同的初始质心将空间分割为不同的 Voronoi 图，梯度下降沿着不同的路径滑入不同的局部极小值。K-means 是 ch3 中"地形决定终点"在无监督学习中的完美实例。

## 10.7 同一种几何，七种语言

线性回归、逻辑回归、PCA、SVD、SVM、K-means。六个算法，六种不同的数学形式——但它们共享同一个几何灵魂：**在一个空间中，找到一个方向或一个位置，使某个几何量达到极值。**

线性回归最小化垂直距离的平方和。逻辑回归最大化似然——等价于最小化交叉熵，在概率空间中寻找最好的分离边界。PCA 最大化投影方差——找到数据云的主轴。SVD 分解旋转与缩放——揭示线性变换的内在几何结构。SVM 最大化分类间隙——找到最宽的空隙。K-means 最小化类内平方和——划分空间为 Voronoi 区域。

这些算法出现在不同的时代，由不同的数学语言书写。但当你在参数空间或数据空间中画出它们的地形——椭圆碗、概率曲面、数据椭圆、Voronoi 图——你会发现，它们都在做同一件事：**沿着某个几何量的梯度，走向某个极值的位置。**

下一章，我们将从经典算法跃入深度架构。Attention 不是"计算注意力权重"——它是 token 之间的一种软几何连接。LoRA 不是"低秩矩阵分解"——它是参数空间中的一个低秩子空间运动。

## 10.8 本章小结

本章用六种经典算法展示了同一个命题：**代数公式的背后是几何事实。**

线性回归的闭式解是椭圆碗的底部。逻辑回归的决策边界是概率曲面上的分水岭。PCA 的主成分是数据云的长轴。SVD 的奇异值是线性变换在各个方向上的缩放因子。SVM 的最大间隔是两类数据之间的空隙。K-means 的质心是 Voronoi 镶嵌的中心。

每一个你背过的公式——$\hat{\beta} = (X^TX)^{-1}X^Ty$，$\max \frac{2}{\|w\|}$——都对应着参数空间或数据空间中的一个几何对象。学习这些算法，不应该只记住它们的公式——而应该看见它们的地形。

## 悬而未决的问题

1. 线性回归的椭圆碗是完美的——但现实中的数据几乎从来不是线性的。在非线性特征变换后，损失地形是否仍然保持某种"近似碗形"——还是变成崎岖的非凸地貌？

2. 逻辑回归的 Hessian 依赖于当前参数位置 $\theta$。在优化过程中，Hessian 的特征谱如何演化？是否存在一个"最优路径"使曲率始终保持在一个有利的范围内？

3. PCA 假设主成分是正交的。在什么条件下这个假设在几何上是合理的？如果数据流形是弯曲的，PCA 的线性主轴是否仍然有意义——还是需要用非线性降维（如自编码器）来"展开"流形？

4. SVD 的奇异值衰减速度决定了矩阵的"有效秩"。在深度网络的权重矩阵中，奇异值谱在训练过程中如何变化？是否随着训练的推进，奇异值集中在少数几个大值上——意味着网络"学会了更紧凑的表示"？

5. SVM 的最大间隔只由支持向量决定。在深度表示空间中，是否存在类似的"支持表示"——即少数几个关键隐藏状态决定了分类边界？

6. K-means 的 Voronoi 镶嵌依赖于欧几里得距离。如果数据的内在度量不是欧几里得的（如文本嵌入中的余弦相似度）——Voronoi 图会变成什么样？是否存在"Bregman K-means"——用 KL 散度代替欧几里得距离？

7. 所有这些经典算法都有闭式解或凸优化保证——它们"保证收敛到全局最优"。深度网络失去了这些保证。是否可能在深度网络和经典算法之间找到一座桥梁——例如，证明某些深度架构在特定条件下等价于某个经典算法的非线性推广？

8. 经典算法在低维数据上运作良好，但在高维数据上往往失效（维度灾难）。深度网络通过表示学习"降维"——将高维原始数据映射到低维流形。从几何视角看，深度网络是否可以理解为"先做非线性 PCA，再做线性分类"的级联？

9. PCA 和自编码器都是降维方法——但 PCA 是线性的，自编码器是非线性的。它们的"隐空间"在几何上有何本质不同？自编码器的隐空间流形在什么条件下退化为 PCA 的线性子空间？

10. SVM 的核技巧将数据映射到高维空间，在那里寻找线性分割。这与深度网络的"表示学习"在本质上有何不同？深度网络学到的是"数据自适应的核"吗？

11. K-means 假设每个聚类是球形的。在表示空间中，类别可能形成任意的流形。是否存在一种"流形 K-means"——用测地线距离代替欧几里得距离来定义"最近质心"？

12. 如果我们把经典算法的几何全部画在同一张参数空间图上——椭圆碗、概率曲面、数据椭圆、Voronoi 图——它们之间是否存在某种"几何对偶"关系？例如，PCA 的主轴和 SVM 的最大间隔方向之间是否有内在的数学联系？

---

**本章留下的核心问题是：**

**经典算法的几何是清晰的——椭圆碗、数据云、Voronoi 图。深度网络的几何是复杂的——非凸、高维、充满鞍点和盆地。两者之间的鸿沟，能否用同一种几何语言来跨越？**
